Abra o CSV de um boot

Arraste o arquivo para cá ou use o botão. Tudo é processado no navegador.

Exportação da tabela reading (colunas obrigatórias: t_ms, pid, value):

\copy (SELECT boot_generation, boot_id, t_ms, pid, value
       FROM reading
       WHERE dongle_id = 1 AND boot_generation = 0 AND boot_id = 7
       ORDER BY t_ms) TO 'boot.csv' CSV HEADER
