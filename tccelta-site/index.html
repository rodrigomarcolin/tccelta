Descrição sucinta do projeto

>>> NOVO!!! <<<

O tccelta é um Sistema de Coleta de Telemetria Veicular baseado em OBD-II. Um dongle OBD-II conecta-se à rede CAN do carro e realiza a coleta dos dados do veículo. Esses dados são exibidos em tempo real no aplicativo, que também intermedia o envio das informações ao servidor. O servidor, por sua vez, armazena e processa os dados coletados e disponibiliza uma API para a visualização das informações.

🚗 ➡️ 🔌 ➡️ 📱 ➡️ 🖥️ ➡️ 📊

Como funciona

Todo carro possui vários subsistemas, cada um controlado por uma Unidade Eletrônica de Controle (ECU). Essas unidades se comunicam através da rede interna, chamada rede CAN.

Já pensou se existisse um sistema capaz de conversar com essa rede de modo a coletar dados de sensores? Um sistema livre e gratuito, construído publicamente, de código aberto? Um sistema que provesse uma versão funcional e que pudesse ser utilizado como base para outros futuros projetos? Um sistema apoiado por uma documentação didática que explicasse todos os conceitos necessários para entender e melhorar o projeto? Já pensou?

Esse sistema existe graças ao TCCELTA!

O que faz

  • Lê parâmetros OBD-II do veículo
  • Lê e limpa códigos de erro (DTCs)
  • Coleta e armazena dados do funcionamento durante o percurso
  • Permite a visualização dos dados coletados
